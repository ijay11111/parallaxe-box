### 路径假象（均非本轮成对实测）

系统 DNS 解析结果是本机解析器的视角；使用远端解析的代理时，它未必是实际建连的地址。TUN 和系统代理同时启用只说明有两种接管机制，不能单凭接口存在断言双重代理或泄露。应分列请求选择的代理、系统选路和真正可见的对端；看不到后半段就留空。共享 CDN 还可能用 [Anycast](https://www.rfc-editor.org/rfc/rfc4786) 从多处宣告同一地址，因此同 IP/ASN 不证明同机房、同业务或同地区。

[HTTP/3](https://www.rfc-editor.org/rfc/rfc9114) 使用 QUIC；若 UDP 路径不通，支持回退的客户端可能改走 TCP，而只支持某条路径的客户端可能失败。只见一次 HTTP/1.1 协商不能证明 UDP 被封；没有专门且获准的 QUIC 观测记“未测”。已知严格 Global、多个国内目标异常、并有同条件路径对照，才支持“疑似错分流”；不能从淘宝 TLS EOF 或一个共享出口上的挑战推出他人历史行为。

## 四个失效案例：失效的是哪条推论？

1. **旧首页选择器** `name="region" value="XX"`：S1 记录已失效；03 首页取得正常标题和内联字段仍未见旧键。废弃此规则，不能将空串解释为默认美国；旧样本只作反例。
2. **国家域名不是国家**：[Google Search 公告，2025-04-15](https://blog.google/products-and-platforms/products/search/country-code-top-level-domains/)说明逐步将国家域名归并到 `google.com`。03 的英国入口本次 301 到主域。公告与一条首跳均不证明所有国家在同一天切换；不要用最终域名判国。
3. **`num=100` 不是固定采样量**：[Ahrefs 自家排名跟踪服务公告，2025 年 9 月](https://ahrefs.com/blog/google-serp-changes-update/)报告旧取样方式中断。不是 Google 对普通搜索恒返 10 条的承诺，也与指定 API 的分页契约不同。没有本项目授权的普通搜索分页实测；不数结果、不发自动搜索作验证。见 [ADR-002](../../docs/decisions.md)。
4. **11 秒首包不是地区拒绝**：[S1 复盘 §0/5（内部设计记录，不随仓库公开）记录 Gmail 等先等 IPv6、后回落 IPv4。属于历史路径，03 未指定远端 IP 族，不能复证。IPv6 慢且最终成功才记 `IPv6_SLOW`；v6 失败、同条件 v4 成功才支持该路径 `IPv6_BROKEN`；只证实 v6 可用且 v4 不可用可记 `IPV6_ONLY_EGRESS`。8 秒是受控回落预算，不是封禁阈值；[RFC 8305](https://www.rfc-editor.org/rfc/rfc8305)解释双栈竞速，不证明某个客户端一定等 10 秒。

## 什么时候报 SIGNAL_STALE

建议 N=3（设计取值，不是统计置信率）：保留一次改版/两次偶发缺失的余地，又不会无限等。按目标 URL/表面、字段语义及解析规则版本、网络路径/地址族、无参匿名请求形态分别计数；没有历史合格命中的候选只是“待验证”。若路径身份无法稳定识别，不跨次累加。只用用户本来就要执行的不同运行，不为凑 N 发请求。

- 合格样本：同一预期页面、状态与内容类型合适、完整未截断、无挑战/登录/限流，才检查字段。前两次完整未命中报 `UNKNOWN + FIELD_MISSING`；第三次报 `SIGNAL_STALE + 连续次数/最后命中日期/失效规则版本`，停止作判定依据。
- 超时、取消、重试、同一缓存样本、换版/换路径、登录和不完整页均不是解析失败；不可比样本不递增，另记原因。相同键的合格命中清零；已隔离规则即使命中也仅恢复观察，人工确认语义后才可再提准入。7 天展示窗口（03）不是三次缺失的替代。例：命中 → 缺 → 超时 → 缺 → 缺，末次才 stale。

## 当证据不一致

先按服务、表面、量纲、路径和 v4/v6 分桶。只在同桶比较相互独立、确有观察值的证据；参数回显、同一跳转的三个键、边缘机房与可达性不投出口票。对同一问题，明确来源的直接观察优先于页面版次，再优先于未公开字段；展示主信号用于解释，**不覆盖反证**。若同层矛盾，输出 `CONFLICT`、列出每条值/来源/强弱/时刻，平级平票主值为空，不取平均；不同层或子域的不同值并列为差异而非伪冲突。例：CF 的 US 与 Books 未见字段不是两票；S1 的 Books/其他表面差异不合成全 Google 国家。缺失、冲突、stale 和单次弱信号均不进入 Guard。
