## 不能可靠下结论的目标

| 表面（验证状态） | 实际能证什么；什么会让推论失效 | 地区/资格与处置 |
|---|---|---|
| Google 首页/Gemini Web（已测） | 两份不同页面碰到相同三字母；字段用途无官方契约，壳页/实验可变化 | 字段存在高、地区含义低；不能判准入、订阅或全 Google 国家 |
| Books / Preferences（首跳已测，旧字段待验证） | 200 有页面但没见历史内联码；S1 在另一时空曾记录 Books 为 CHN | 单次未命中不说明地区或永久失效；按 05 计数，不借 Gemini 的值 |
| News（已测一跳） | 可控版次参数出现在 Location，包括 `ceid=US:en`；请求、缓存和语言可改变它 | 版次中、出口无；不以其填 IP 国家 |
| YouTube 首页 / Music（首跳已测） | 首页有 GL，Music 无相同样本；用户设置、默认值、同意页可改变表面 | 首页仅内容版次；不复制同意态。无授权时不再在线采样 |
| YouTube Premium（首跳已测；会员资格禁止验证） | 营销页 200 不代表可购买/播放；依赖 Cookie、账号或付款的检法越界 | 资格 `NOT_OBSERVABLE_ANONYMOUSLY`；不存/复用 Cookie、不试购 |
| Play `/store` / `/store/apps` / 账号页（首跳已测） | 跳转或国旗资源不等于选中项；目录、账号 Play 国和付款档案是三件事 | 素材低，账号付款不可测；不补付费样例 |
| Play 下载 CDN（仅文档/历史 S2） | gvt1、`dl.google.com` 等受地理调度和多服务共享；未请求包、无设备下载路径 | 用户下载成功率和实际 CDN 待验证且不主动下载；默认保护，不按 IP/CDN 阻断 |
| Accounts / OAuth / GSI / reCAPTCHA，及转向登录的 Drive 等（已测入口） | 路由交接或静态脚本送达；没有身份、资源或验证上下文 | 连通性或 `UNKNOWN`，不登录、不穿过挑战，保护整条链 |
| Gemini API、Cloud/Workspace 管理和教育入口（已测公开面） | 无 key 模型列表 403；文档/控制台与项目 IAM、额度、区域、学校策略不同 | 拒绝原因未证；项目、租户、模型权限不可匿名验证 |
| `ggpht.com`、`ytimg.com`、`googlevideo.com` 裸根（已尝试，未取得 HTTP） | 前两者超时，后者证书验证失败；不等于整个图像/视频下载链断 | 对失败事实高，对原因低；不跳过证书校验，服务/地区待验证 |
| ChatGPT / Claude / Grok、GitHub/npm/PyPI（只测状态/文档页） | 状态/文档可能独立路由；成功不证明应用、私库、模型或包分发可用 | 静态入口最多 `REACHABLE_ONLY`，业务面未测；不打开登录/鉴权 |
| Netflix / Disney+ / Prime Video / Spotify 等（条款/帮助页已测） | 版权、市场、订阅与账号有关；不请求片库、授权或 DRM | 不报“可播放”，见 [08 的在线准入门槛](08-compliance.md) |
| X 帮助页 / 淘宝首页（分别 403 / TLS EOF） | 对当前响应或握手事实高，对服务策略归因低；可有风控、路径或本机原因 | 不报封国/错分流；国内组只对比同条件路径，详见 04 |
| CF trace / speed meta（已获响应） | trace 的 `loc` 与 `colo` 属不同量；speed 403 无目标字段；代理换路影响结果 | 仅 trace 该路径有出口映射，不作为 Google 信号，不算两家独立证据 |

## TECH-REF §G：五项逐一结账

| 编号 | 验证状态、可复核样本 | 尚缺什么 / 下一步（只在已获准路径） |
|---|---|---|
| G1 `generate_204` 地区头 | **已实测单路径；地区头未证**。03 `google.http204`：204、0 B、所检查头名命中 0。不是证明全网永无此头 | 保留连通性，不启地区解析；如有带文档语义的新头，仅核必要字段，不收整套头 |
| G2 `ceid` | **已实测一个匿名值；通用格式待验证**。03 `google.news`：裸入口 302 的同一 Location 含 `hl=en-US`、`gl=US`、`ceid=US:en` | 一条样本不能规定全部语言/地区/分隔方式；仅展示版次，不主动构造地区覆盖来“验证”出口 |
| G3 各服务匿名 handler | **部分实测**。03 的 107 次尝试中 104 个得首跳；04 的 28 次得 27 个。命中、未命中、挑战/无凭据和未获 HTTP 按行看；状态站不是业务 handler | 复审许可、同一表面及截断/内容类型、跨运行语义；依赖账号/Cookie/付费或禁止自动访问者不做在线复测。严禁笼统标“全部有效” |
| G4 国家域重定向替代判据 | **旧推论已排除；可靠替代待验证**。Google 2025-04-15 归并公告 + 03 英国域 301 → `www.google.com`；03 `/search` 首跳没有 IP 来源页脚 | 没有可替代所有服务的单一规则。维持分表面 `UNKNOWN`，不提交自动搜索；版本、语言或 DNS 不是替代项 |
| G5 `--proxy` / `--interface` 路径一致性 | **待验证**。只有既有研究代理，未绑网卡，无同时间、同地址族的成对请求；不能证明代理远端族或 DNS | 需用户已有且许可的两条路径，对同一目标、同族记录请求路径与实际连接，在独立回显端比较出口并区分接收方。无法观测的一侧留空，仍不足以证明全站同路；不切节点、不改系统 |

## 来源等级按问题选，不按票数选

| 标签 | 能回答的问题 | 不能据此断言 |
|---|---|---|
| `OFFICIAL_DOC` 官方帮助、政策、标准 | 产品支持范围、条款、字段/协议的公开语义；查阅日、适用产品/地区要一致 | 当前出口值、登录资格或实际出现过字段 |
| `DIRECT_ANONYMOUS_OBSERVATION` 直接实测 | 给出日期、入口、路径、方法、字段/状态的那个样本；03/04 是前次研究留存的这类证据 | 跨族、跨服务、跨次或永久有效；搜索工具/官方文档预览不是用户节点实测 |
| `COMMUNITY_REPORT` 社区/运维经验 | 现象和复核线索；例如 Ahrefs 自述分页失效，或内部会话的转述 | Google 未公开协议、共享边界、其它用户的同一结果 |
| `LEGACY_CODE` 历史代码 | 特定版本曾经尝试如何解析 | 当前匿名响应仍存在，或允许运行/复制 |
| `INFERENCE` 推测 / 研究建议 | 提出可证伪的假设、保守阈值和设计建议 | 不填地区、默认配置或 Guard；证据不足用 `null + reason` |

复核顺序：查适用的官方语义/许可 → 确认测的是同一主机、表面、地址族和量纲 → 比较带时间的实际片段 → 记录反证及不可比条件。会话中能定位的实际字段记作**历史样本**，对因果的转述仍是经验。冲突写 `docs/decisions.md`：原说法、日期、双方来源及等级、采用理由、默认策略、重审条件。现有公开摘要见 [工程决策摘要](../../docs/decisions.md)。**本阶段无新增默认目标或规则**；单路径命中不是发行准入。
