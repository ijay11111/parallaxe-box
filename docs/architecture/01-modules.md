# 01 模块边界：一次判定，三个入口

阶段 1 设计 · 2026-11-21。交给阶段 2 的接口边界，不是现存 crate。单文件指交付一个二进制；不意味着把联网、策略与 UI 写在一个模块。

```text
parallaxe-box（组合根：按子命令选择适配器，可不构建 GUI）
  ├─ cli   ───┐   clap 参数、人读表格/退出进程
  ├─ agent ───┼─→ parallaxe-core 公共门面：submit / subscribe / snapshot / replay
  └─ gui   ───┘   egui/eframe 只在 GUI 一侧；无远程控制端口

core 内，箭头表示“左侧依赖右侧”，不是网络数据流：
  门面/运行协调器 → targets、probe、signals、verdict、guard、reports、events
  probe → targets（已准入的请求描述）、network（受预算限制的传输端口）
  verdict → signals（已归因的证据）；guard → targets（保护和依赖视图）
  reports → events（投影已提交的事件）；网络、准入与判据不依赖 reports
  targets、network、signals、events 等叶模块 → contracts（纯值类型，不依赖上层）
```

| 模块 | 拥有的决定 | 明确不负责 |
|---|---|---|
| `targets` | 验证四件套及独立信号规则 TOML、建不可变目录/依赖索引、展开选集；按内嵌许可核对精确 URL/方法/用途/有效期 | 不发请求；外部覆盖不构成授权 |
| `probe` | 只接收一次性、绑定运行与地址的准入描述，管理排队、单目标预算、超时、取消、回落、去重；转交脱敏样本 | 不提供可绕开准入的裸 URL 接口；不根据 HTTP 403 判国 |
| `network` | 在线传输端口及只读系统路径观测；明确地址族/代理/DNS 的可见范围；离线端口与在线端口分离 | 不读浏览器/订阅，不改系统，不负责地区判定 |
| `signals` | 对限定表面的样本执行白名单 reader，提取最小字段，给出量纲、缺失原因和来源 | 不投跨服务票、不存正文、不发起“补抓” |
| `verdict` | 汇总独立证据、冲突、按键的 stale 历史、四层结论；按 ADR-003 归约运行结果和退出码 | 不接触原始传输，不读 UI 配色，不能生成阻断规则 |
| `guard` | 输入终态结果、实际用户选择和图快照；输出纯数据的影响闭包及不可应用原因 | 不拥有系统写入或联网能力 |
| `events` | 对每个运行单写者编号，提交不可变事件；提供重放、订阅和终态锁定 | 不排序“哪个国家正确”，不按接收端改判定 |
| `reports` | 由相同事件/终态投影形成报告、覆盖两栏和各格式；共用脱敏及转义 | 不重新求 state 或退出码；adapter 只处理目的地、格式、显示 |

准入在两个时刻执行：`targets` 展开选集后区分“注册/被选/获准”，`probe` 在交给传输**之前**复查请求描述、有效期、运行预算和取消状态。没有许可时连 DNS 也不发；系统路径探测同样不能借页面预检偷发回显请求。当前内嵌许可为空，默认/自选/full 都会展示未覆盖原因。裸主机匹配、用户优先级、历史 200、跳转、改 `targets.toml` 均不能扩权。

**目录说明**：按 [ADR-004](../../docs/decisions.md)，未来 workspace 根即 `G:/test-ip` 本身，不建同名子目录。本轮实际提供 `docs/architecture/` 与 `assets/`；将来 `crates/{core,cli,agent,gui}/`、`tests/fixtures/` 是职责边界，不在此创建项目骨架。默认 assets（含独立规则表）和批准的离线 fixture 以后嵌入二进制，优先级示例不当成用户配置。离线运行使用同一判定门面、合成样本提供者和虚拟时钟；不给它 HTTP 客户端、resolver、系统状态写入器或在线回退。fixture 只替代输入，不替代 `verdict`。

**阶段 2 验收办法**：无 GUI 构建与依赖树中 core 无 egui/eframe/clap；适配器只通过门面使用契约，搜不到自写的国家判据或退出码表。对被拒目标注入计数传输器，应是零调用；对同一 fixture 的三种订阅比较序号、判定、覆盖和请求计数。依赖反向、需要显示器才能 selftest、或 GUI 与 JSON 任一不同，均退回。
